# DIAI-F-001 - Ограничение ввода номера при выборе способов для связи

## Summary

В форме запроса демо при выборе **WhatsApp** в качестве способа связи невозможно указать номер с кодом страны, отличным от **+7**.

Маска поля телефона принудительно использует код **+7**, из-за чего пользователи с иностранными номерами не могут корректно указать контактный номер.

dialogic-ai.ru

## Description

### Environment

* Web version
* Browsers: Chrome, Firefox
* URL: https://dialogic-ai.ru/

---

### Steps to Reproduce

1. Перейти на сайт **https://dialogic-ai.ru/**.
2. Открыть форму запроса Демо.
3. Выбрать **WhatsApp** в качестве способа связи.
4. Перейти к полю ввода номера телефона.
5. Попытаться указать номер с международным кодом страны, отличным от **+7**, например **+995**.
6. Обратить внимание на маску и доступный формат ввода номера.

---

### Expected Result

* Пользователь может указать номер WhatsApp с международным кодом своей страны.
* Поле поддерживает номера с кодами стран, отличными от **+7**.
* Например: **+995**, **+49**, **+372** и другие валидные международные коды.
* Валидация номера не должна ограничивать форму только пользователями с номерами **+7**.

---

### Actual Result

* В поле телефона установлена маска с фиксированным кодом **+7**.
* Изменить код страны невозможно.
* Ввести номер телефона с другим международным кодом невозможно.
* Пользователи с иностранными номерами не могут корректно указать номер для связи через **WhatsApp**.
